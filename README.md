# JARVIS — protótipo inicial

Protótipo web/PWA em português, com interface futurista, chat local, comandos básicos de data/hora, síntese de voz e reconhecimento de voz quando suportado pelo navegador.

## Publicação
Envie todos os arquivos desta pasta para a raiz do repositório GitHub `jarvis-assistente`. Depois abra Settings → Pages, selecione Deploy from a branch, escolha `main` e `/ (root)` e salve.

## Limitações
Este protótipo ainda não está conectado a uma IA, não possui memória permanente nem controla aplicativos ou dispositivos. Não inclua senhas, chaves de API ou dados pessoais no repositório público.
